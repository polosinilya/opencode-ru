# opencode-ru

Русифицированный форк [opencode](https://github.com/sst/opencode) — открытого AI-агента для кодинга в терминале.

> **Неофициальный форк.** Проект не связан с разработчиками оригинального opencode и не поддерживается ими. Весь оригинальный код принадлежит его авторам и распространяется под лицензией [MIT](LICENSE). Здесь публикуются только сборки с русской локализацией и доработками.

## Что добавлено к оригиналу

- **Русский интерфейс** — TUI и CLI локализованы: меню, диалоги, подсказки, описания команд, слэш-команды.
- **Нативное автоисправление раскладки** — работает прямо в TUI, без внешних утилит (`ydotool`, `xclip` и т.п.):
  - `Ctrl+Alt+Z` — исправляет раскладку выделенного текста или последнего слова: `Ghbdtn` → `Привет`, `Руддщ` → `Hello`;
  - одинаково работает на Linux и Windows.
- **Проверка раскладки перед отправкой** (опция `layout_check_on_submit`, по умолчанию выключена):
  - перед отправкой промпт проверяется по словарю; если найдены слова в неверной раскладке — показывается диалог с исправленным текстом («Отправить исправленное» / «Отправить как есть» / «Отмена»);
  - работает в промпте сессии, на стартовом экране и в ответе на вопрос модели;
  - слова, отправленные «как есть», запоминаются в персональный словарь `~/.config/opencode/layout-words.txt` и больше не подсвечиваются.

## Установка

Готовые сборки лежат в разделе [**Releases**](../../releases).

### Linux (deb, amd64)
```bash
sudo dpkg -i opencode_1.18.31-ru.0008_amd64.deb
opencode --version
```

### Windows
Скачайте `opencode-ru-setup.exe` и запустите — установка per-user, без прав администратора.

**Чтобы интерфейс был на русском**, задайте переменную окружения `OPENCODE_LANG=ru` — на Windows переменные локали (`LANG`/`LC_ALL`) обычно не заданы, и без этого интерфейс останется английским.

PowerShell (один раз, для текущего пользователя):
```powershell
setx OPENCODE_LANG ru
```
Затем перезапустите терминал и opencode.

Либо вручную: «Параметры → Система → Дополнительные параметры системы → Переменные среды» → создайте переменную `OPENCODE_LANG` со значением `ru`.

> На Linux обычно достаточно системной локали (`LANG=ru_RU.UTF-8`), но `OPENCODE_LANG=ru` тоже работает и имеет приоритет.

## Включить проверку раскладки перед отправкой

Добавьте в `~/.config/opencode/tui.json`:
```json
{
  "layout_check_on_submit": true
}
```
и перезапустите opencode.

## Сборка из исходников

Форк основан на `sst/opencode`, ветка `dev` (актуальная база — `1.18.30`). Локальные коммиты: русская локализация TUI/CLI и фичи автоисправления раскладки.

```bash
git clone git@github.com:polosinilya/opencode-ru.git
cd opencode-ru
bun install
```
